## Блокеры (исправить в раунде 2)

**B1. Чекбокс `CheckboxInput` — область 16×16 px, а не 32×32 (A4; отчёт утверждает обратное).**
`className="box-content h-4 w-4 p-2"` не даёт 32 px: Chromium не применяет padding к нативному чекбоксу, замер в живой странице — `input` 16×16, computed `padding: 0px`, обёртки `label` у этого чекбокса нет («Экстренная остановка» на `/strategies/new`). Два других чекбокса в `StrategyFormPage.tsx` (строка ~674) — внутри `label` 1044×20 px: кликабельная область есть, но 20 px по высоте. Требование A4 — интерактивные элементы ≥ 32 px. Исправление локальное: например, обернуть чекбокс в `label` с `min-h-8` и `min-w-8` (подпись у `CheckboxInput` уже есть как `aria-label`, видимые тексты не менять), либо сделать кликабельной область всей строки с `min-h-8`; то же — для чекбоксов `StrategyFormPage.tsx`. Добавить тест/проверку на размер области (или явный комментарий в отчёте, как проверено).

**B2. `PeriodPicker`: Esc не закрывает календарь, открытый с клавиатуры (A6; отчёт: «дефектов не найдено»).**
С клавиатуры календарь открывается кнопкой «Открыть календарь» (Tab → Enter) — открывается. Но фокус остаётся на кнопке, а обработчик `onKeyDown` (Esc) повешен только на текстовое поле и на сам диалог, поэтому Esc на кнопке ничего не делает (живая проверка: после Enter диалог открыт, после Esc — остался открытым). Исправление локальное: повесить `onKeyDown` на кнопку (или на общий корневой `div`) и/или переносить фокус в диалог при открытии. Контракт A6 требует исправить локальные дефекты. Добавить тест на Esc.

**B3. Placeholder: цвет изменился в Tailwind 4 и не покрыт проверкой контраста (A1 «весь текст ≥ 4.5:1»).**
В v4 цвет `::placeholder` по умолчанию — текущий цвет текста при 50% непрозрачности (в собранном CSS: `color-mix(in oklab, currentcolor 50%, transparent)`), в v3 был gray-400. Расчёт: поля `inputClass` (zinc-100 на zinc-900) — 4.88:1 (было 6.98:1); поля даты/времени `PeriodPicker` (zinc-200 на zinc-950) — **4.42:1 < 4.5**. axe плейсхолдеры не проверяет, `check:contrast` — тоже. Исправление: одно правило в `@layer base` — `::placeholder { color: var(--color-text-muted); }` (6.91:1 на surface, 7.76:1 на page) — одновременно возвращает вид, близкий к v3, и закрывает A1 для плейсхолдеров. Изменение v4 для placeholder перечислить в REPORT (T2).
