## Контракт

### Часть 1 — Tailwind 4 (отдельный коммит(ы), визуально 1:1)
- T1. Перейти на последнюю **stable** Tailwind 4.x (`latest` на npm; без beta/rc) по официальному upgrade guide. Использовать `@tailwindcss/vite` (или `@tailwindcss/postcss` — выбрать по guide и обосновать в REPORT); убрать `autoprefixer`/`postcss.config.js`/`tailwind.config.js`, если они больше не нужны.
- T2. Конфигурация CSS-first (`@import "tailwindcss"`, `@theme`). Применить **только** изменения, которые требует upgrade guide (переименованные утилиты, изменённые дефолты border/ring/outline и т. п.); перечислить их в REPORT. Не делать «заодно» рефакторинг классов.
- T3. Сравнение «до/после»: скриншоты всех страниц (Обзор, Инструменты, Стратегии + форма, Бэктест, Боты, Сделки/прочие существующие) до и после Части 1; различия — только допустимые и перечисленные в REPORT.
- T4. Совместимость браузеров Tailwind 4 (Safari 16.4+/Chrome 111+/Firefox 128+) — зафиксировать в `frontend/README.md`.

### Часть 2 — токены и доступность (отдельные коммиты)
- A0. Токены: в `@theme` объявить семантические токены (фон страницы, поверхность, граница, текст основной/вторичный/приглушённый, акцент, ошибка, предупреждение, успех) на базе **существующих** zinc-значений; новые классы использовать в общих компонентах (`InstrumentPicker`, `PeriodPicker`, кнопки/поля, шапка). Массовую замену во всех 6000 строк **не** делать — только общие компоненты и места, затронутые A1–A5.
- A1. Контраст: весь текст интерфейса ≥ **4.5:1** (WCAG AA) на своём фоне; `text-zinc-500/600` на тёмном фоне заменить токеном вторичного/приглушённого текста с достаточным контрастом. Результат — таблица «где было → где стало → отношение» в REPORT (посчитано формулой WCAG, не «на глаз»).
- A2. Подписи полей: каждый интерактивный элемент (input/select/textarea/button без текста/combobox) имеет программную подпись (`label htmlFor`, `aria-labelledby` или `aria-label`). Приоритет — «Бэктест» (7 из 17 без подписи), затем остальные страницы. Видимые тексты не менять.
- A3. Фокус: единый видимый индикатор `:focus-visible` для кнопок, ссылок, полей, элементов списка `InstrumentPicker` (через токен/базовый слой). Не убирать `outline` без замены.
- A4. Цели нажатия: интерактивные элементы высотой ≥ 32 px (мелкие иконочные кнопки — с `min-h`/padding); не ломать вёрстку таблиц и строк.
- A5. Фон и тема: `body` имеет явный фон и цвет текста из токенов; `color-scheme: dark` (интерфейс только тёмный); при светлой теме ОС не появляется белых подложек.
- A6. Клавиатура: `InstrumentPicker` и `PeriodPicker` управляются с клавиатуры (Tab/стрелки/Enter/Esc) — проверить; найденные дефекты исправить, если правка локальна, иначе описать в REPORT.
