## P2. Контракт выбора бумаги

- Подпись везде: **«Ценная бумага»** (`BacktestPage`, `BotsPage`).
- Выбора по умолчанию нет — поле пустое, обязательно.
- Пикер работает по **FIGI**; страницы переводят в локальный `instrument_id`
  (`chosenInstrument` / `onSelectInstrument` в обеих страницах).
- Бумаги с `id === null` **не появляются в списке**: фильтрация выполнена один
  раз центрально в `InstrumentPicker` (`selectable = instruments.filter(i => i.id !== null)`),
  счётчик «Найдено: N из M» показывает выбранное подмножество.
- Текст ошибки при пустом выборе: **«Выберите ценную бумагу.»**
  (было «Выберите инструмент.»).
- Если список инструментов не загрузился: **«Инструменты не загружены.»**
  (вместо пустого пикера).
- Отображение уже выбранного инструмента в карточках ботов — **не менялось**
  (там метка строится через `useBotDisplayMeta`, без участия пикера).
- Поведение MVP-7.6 в «Бэктесте» сохранено: подсказка «Данные для бэктеста
  доступны с…», фильтр пресетов, сброс периода «Весь период», границы календаря.
- Фолбэк-подпись пикера при выбранном `instrument_id` без FIGI: `#<id>`.
