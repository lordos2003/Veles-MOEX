- Переименовать в **«Ценная бумага»**; выбор — **тем же способом, что «Рынок» на «Обзоре»** (поиск с выпадающим списком, U2 MVP-7.4): использовать общий компонент (при необходимости вынести из `OverviewPage` в `components/`), не копировать.

- В конфиг по-прежнему сохраняется `instrument_id` (локальный id); контракт API и схему не менять; значение по умолчанию не подставлять (MVP-7.1, U4); обязательность поля не менять.
- `SEGMENT_LABELS.instrument_id` в `lib/labels.ts` → «Ценная бумага».
- Существующая стратегия открывается с подписью бумаги, а не числом.
- Тесты vitest: выбор по тикеру → верный `instrument_id`; пустой выбор → ошибка у поля; загрузка существующей стратегии показывает подпись.

## U10. «История, баров» убирается из формы, глубина считается автоматически (решение владельца 2026-10-08)

Факты: `lookback_bars` — проектное поле (`StrategyConfig.lookback_bars`), в Veles его нет. «Период» в Veles — диапазон дат бэктеста, это не оно. Сейчас без поля живой цикл не стартует (`LookbackNotConfigured`); документация Veles формулы глубины не задаёт (`market_context.py`). Рекурсивные индикаторы (EMA, MACD, RSI, ATR) зависят от всей истории, поэтому глубина влияет на их значения.

Требуется (после утверждения формулы владельцем):
- убрать поле из формы и из JSON-шаблона формы; в схеме `lookback_bars` остаётся необязательным (старые стратегии с ним продолжают работать, явное значение приоритетнее расчётного);
- если поля нет — глубина считается движком по утверждённой формуле; `LookbackNotConfigured` больше не блокирует цикл при наличии расчёта;
- `SEGMENT_LABELS`/подсказки обновить; бэктест не менять.
- Тесты: расчёт по формуле на наборе индикаторов (SMA, EMA, RSI, BB, свечи со сдвигом), явное значение приоритетнее, стратегия без индикаторов.

### Открытое решение владельца: формула глубины
Вариант A (минимум): `N = max(период_i + сдвиг_i)` по всем индикаторам условий входа и выхода (+1 бар на формирующуюся свечу).
Вариант B (с запасом для рекурсивных): как A, но для EMA/MACD/RSI/ATR период умножается на фиксированный множитель (предлагается 5), затем `+ сдвиг` и `+1`.
